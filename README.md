# 精灵伴侣成长计划

<p align="center">

</p>

一个纯前端、零后端的个人生活管理工作台。把**财务投资、运动健康、塔罗客户、入手+断舍离、读书进度**五大板块整合在一个轻盈的手帐风界面里，所有数据只存在你自己的浏览器（localStorage），不依赖任何服务器、不上传任何云端。

> 设计基调：温暖、轻盈、手帐风。柔和的纸张底色 + 宋体标题 + 圆润卡片，红涨绿跌遵循 A 股惯例。

---

## ✨ 功能模块

| 模块 | 说明 |
| --- | --- |
| **仪表盘** | 聚合五大板块的关键指标、智能建议与近期活动时间线 |
| **财务管理** | 净资产/目标进度追踪、月度对账、18 类账户管理、9 类持仓明细、收入与交易记录、**今日财经**（每日全球财经资讯聚合 + AI 总结 + 波动预警） |
| **运动健康** | 身体指标记录与趋势、训练日志、目标追踪、训练/饮食/心理建议 |
| **塔罗客户** | 客户档案（标签/搜索）、占卜记录（78 张牌阵/正逆位/解读）、跟进提醒 |
| **入手+断舍离** | 入手记录（买了什么/何时买/价格）、使用中物品管理、断舍离记录（含「转二手市场流通」净利润统计）、优先使用目标倒计时 |
| **读书进度** | 书架管理（在读/想读/已读/搁置）、每日阅读记录、强制读后感、微信读书 API 对接 |

**财务隐私保护**：仪表盘与财务总览均带「眼睛」显隐开关，一键把所有金额/百分比变为 `¥***`，状态本地持久化。

## 🛠 技术栈

- 原生 **HTML / CSS / JavaScript**（无框架、无构建步骤）
- **Chart.js** 图表（通过 CDN 引入）
- 数据持久化：**localStorage**（纯本地）
- 字体：Noto Serif SC（标题）/ PingFang SC（正文），来自 Google Fonts

## 🚀 本地运行

无需安装依赖，任意静态服务器即可：

```bash
# 方式一：Python（macOS / Linux 自带）
cd <项目目录>
python3 -m http.server 8090 --bind 127.0.0.1

# 方式二：Node
npx serve .
```

然后在浏览器打开 **http://localhost:8090** 即可。

> ⚠️ 必须通过 `http://` 访问（如 localhost），**不要直接双击 `index.html` 用 `file://` 打开**——浏览器会因 CORS 拦截所有数据加载。

## 📊 数据存储说明

- **所有业务数据**（账户、持仓、训练、客户、读书进度等）只存在于浏览器 **localStorage**，换设备/清缓存即清空，没有任何后端。
- `data/` 目录仅存放「今日财经」所需的资讯 JSON。仓库中自带一份**占位示例**，运行数据同步或每日自动化后会自动替换为真实内容。
- **个人数据不出本机**：本仓库不包含任何真实账户、持仓、读书记录。

## 📚 微信读书对接（可选）

1. 在「读书」模块 → 设置 中粘贴你的微信读书 API Key（格式 `wrk-xxxxxxxx`）。
2. 点击「同步书架」即可把微信读书数据拉取到本地书架。
3. 开发者可用 `scripts/weread_sync.py` 处理原始 API 返回，规范化为 `data/weread-sync.json`。

> 密钥仅保存在你浏览器的 localStorage，**不会写入任何文件、也不会进入本仓库**。
